# Input Reference Guide

This document defines the keybindings and control schemes used across the GP-RPGV6.2 engine.

## 1. Gameplay Controls
- **WASD**: Move the player character.
- **E**: Interact with tiles (e.g., reading signs).
- **Shift + Z**: Activate temporary Zoom override.
- **Shift + F**: Toggle Free Camera debug mode.

## 2. Global System Controls
- **`** or **~** or **F1**: Toggle the Developer Console.
- **F11**: Toggle Fullscreen.

## 3. Editor Controls
- **Mouse Wheel**: Smooth, continuous camera zooming.
- **Middle Mouse Button (Drag)**: Pan the map canvas.
- **Space + Left-Click (Drag)**: Alternative mapping to pan the canvas (ideal for trackpads).
- **0 (Zero)**: Fit-to-Screen. Instantly frames the entire map in the editor viewport.
- **Left-Click**: Paint selected tile.
- **Right-Click**: Erase tile (paint void).

## 4. Console Commands (Keybindings Context)
While the console is open, gameplay input is suspended.
- **Up / Down Arrows**: Cycle command history.
- **Tab**: Autocomplete commands.
- **Enter**: Execute command.
