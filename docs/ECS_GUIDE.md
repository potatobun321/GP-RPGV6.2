# ECS Guide

The Entity Component System (ECS) is responsible for the interactive and dynamic objects in the game (Players, NPCs, Projectiles). 
*(Note: Static background tiles are managed by the Tilemap array, not the ECS).*

## 1. Concepts
- **Entity**: Just a numeric ID generated by the Registry.
- **Component**: A plain Lua table holding data. No logic is allowed here!
- **System**: A function called every frame that iterates over entities possessing a specific set of components.

## 2. The Registry (`engine/ecs/registry.lua`)
The registry acts as the database, managing the lifecycle of entities.

### Creating an Entity
```lua
local id = Registry.create()
```

### Adding Components
```lua
local Components = require('engine.ecs.components')
Registry.add(id, "Transform", Components.Transform(0, 0, 32, 32))
Registry.add(id, "Velocity", Components.Velocity(0, 0, 100))
```

### Querying Entities
To avoid $O(N)$ searches every frame, always use `queryCached`:
```lua
-- Returns a list of entity IDs that have both Transform and Velocity
local entities = Registry.queryCached("Transform|Velocity", {"Transform", "Velocity"})
```

## 3. Systems (`engine/ecs/systems.lua`)
Systems contain the actual gameplay logic. When you write a new system, you should:
1. Define its component signature.
2. Iterate through `Registry.queryCached`.
3. Process data.

### Example: Custom System (Poison)
```lua
function Systems.PoisonSystem(dt)
    local entities = Registry.queryCached("Health|Poisoned", {"Health", "Poisoned"})
    for _, id in ipairs(entities) do
        local hp = Registry.get(id, "Health")
        local p = Registry.get(id, "Poisoned")
        
        hp.current = hp.current - (p.dps * dt)
    end
end
```
By organizing code this way, you can easily make a "Poisonous Rock" by attaching the Poison component to a Rock entity, without writing any rock-specific logic!

## 4. Avoiding ECS Pitfalls
- **Do not store functions in components.** Only store simple state.
- **Do not use `Registry.query` inside tight loops.** Always use `queryCached` which memoizes the entity sets.
- **Do not remove components while iterating.** If you need to delete an entity during a system loop, mark it with a component and delete it in a separate Cleanup system if necessary.
