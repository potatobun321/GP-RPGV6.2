# ECS Guide

The Entity Component System (ECS) is responsible for the interactive and dynamic objects in the game (Players, NPCs, Projectiles). Note: Static background tiles are **not** ECS entities.

## 1. Concepts

- **Entity**: Just a numeric ID generated by the Registry.
- **Component**: A plain Lua table holding data. No logic is allowed here!
- **System**: A function called every frame (or specific lifecycle hooks) that iterates over entities possessing a specific set of components.

## 2. The Registry (`engine/ecs/registry.lua`)

The registry manages the lifecycle of entities.

### Creating an Entity
```lua
local id = Registry.create()
```

### Adding Components
```lua
local Components = require('engine.ecs.components')
Registry.add(id, "Transform", Components.Transform(0, 0, 32, 32))
Registry.add(id, "Velocity", Components.Velocity(0, 0, 100))
```

### Querying Entities
To avoid $O(N)$ searches every frame, always use `queryCached`:
```lua
-- Gets a list of all entity IDs that have both Transform and Velocity
local entities = Registry.queryCached("Transform|Velocity", {"Transform", "Velocity"})
```

## 3. Systems (`engine/ecs/systems.lua`)

Systems execute logic. When you write a new system, you should:
1. Define its query signature in `SYS_QUERIES`.
2. Iterate through `Registry.queryCached`.
3. Process data.

### Example: Custom System
```lua
function Systems.PoisonSystem(dt)
    local entities = Registry.queryCached("Health|Poisoned", {"Health", "Poisoned"})
    for _, id in ipairs(entities) do
        local hp = Registry.get(id, "Health")
        local p = Registry.get(id, "Poisoned")
        
        hp.current = hp.current - (p.dps * dt)
    end
end
```

## 4. Avoiding ECS Pitfalls
- **Do not store functions in components.** Only store simple state.
- **Do not use `Registry.query` inside tight loops.** Always use `queryCached`.
- **Do not remove components while iterating.** If you need to delete an entity during a system loop, mark it with a `Garbage` component and delete it in a separate `CleanupSystem`.
